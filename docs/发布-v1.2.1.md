# 发布 v1.2.1（versionCode 103）操作清单

本次改动已在手机端完成编码与编译校验（`javac` 全量通过，Android API 36 + libxposed api 102 + androidx 依赖）。
**APK 打包必须在装了 JDK 21 + Gradle + Android SDK 36 的电脑上做**（设备存储不足以跑 Android Studio 构建，且 `apktool` 重打包会破坏 libxposed 元数据）。

## 1. 取源码

在 PC 上的克隆目录里：

```bash
git am 0001-feat-v1.2.1-103.patch        # 或直接 cherry-pick a37955e
```

## 2. 构建签名 Release

```bash
export JAVA_HOME=/path/to/jdk-21
export TGAS_KEYSTORE=$HOME/.android/tgas-release.jks    # 必须与 v1.1.0/v1.2.0 同一把 key
export TGAS_KEYSTORE_PASS='<key 口令>'
export TGAS_KEY_ALIAS='<别名>'
export TGAS_KEY_PASS='<别名口令>'

./gradlew :app:assembleRelease
APK=app/build/outputs/apk/release/app-release.apk

apksigner verify --print-certs "$APK"      # 核对 SHA-256 与旧版一致，防止老用户无法覆盖升级
```

口令只放环境变量或本机 key 管理器，**不要**再写回 `build.gradle`（v1.2.0 及更早的明文口令建议轮换一次）。

### 必须匹配的签名证书（从 v1.2.0 正式包 APK Signing Block 提取）

    subject / issuer : C=CN, O=wlmosv, OU=TGAutoSign, CN=wlmosv
    serial           : 0705BF9BAA51FD1F
    validity         : 2026-09-07 21:53 UTC ~ 2054-01-23
    公钥             : RSA 2048
    SHA-256 指纹      : AF:55:24:CD:55:4A:E6:ED:E3:EC:27:47:C7:BE:D1:59:B0:9B:C4:F6:A4:32:44:A6:8B:46:22:E9:46:32:25:C8

`apksigner verify --print-certs app-release.apk` 得到的 SHA-256 digest 必须与上面完全一致，
否则老用户只能卸载重装（会丢签到目标）。证书 DER（公钥，可公开）备份：
`Download/TGAutoSign-v1.2.0-release-cert.der`；私钥 keystore 不在这台手机上。

## 4. GitHub Release

```bash
git tag -a v1.2.1 -m "内置检查更新 + 配置导出导入 (103)"
git push origin main v1.2.1        # 分支名以仓库实际为准
gh release create v1.2.1 \
  --repo Xposed-Modules-Repo/io.github.wlmosv_png.tgautosign \
  --title "v1.2.1" --latest \
  --notes-file CHANGELOG-head.md \
  "$APK#TGAutoSign-v1.2.1.apk"
```

- tag 规则：**`v主.次.修`**（`UpdateChecker` 兼容旧 `<code>-<version>` 写法，但今后不要再混用）
- 模块仓库的 Release 必须挂**签名后的正式 APK**，LSPilot/LSPosed 靠它做版本检测
